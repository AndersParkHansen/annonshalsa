# Projektbeslut
- Demon använder en fiktiv artikel med tre platser. Sidfoten lämnas avsiktligt tom som ett återkommande testfall på båda enheterna.
- Standardläget kräver varken konto hos en annonsleverantör eller betaldata. Rapportens prioritering bygger på observerade avvikelser och mätbarhet.
- GitHub Pages visar den syntetiska rapporten. Körningar på verkliga adresser sparas som Actions-artefakter med samma läsbehörighet som repots artefakter. I ett publikt repo kan andra se körningen och hämta resultat.
- Om en ny regel införs ska ett fiktivt exempel visa vad den ska upptäcka och hur ett osäkert mätresultat ska klassas.
